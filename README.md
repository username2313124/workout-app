# 운동기록 앱 — (데스크탑 + 안드로이드 + 아이폰(웹앱))

AI에게 오늘 한 운동을 말하거나 러닝 앱·클라이밍·헬스 앱 기록 사진을 올리면, 정해진 형식으로 폰 안의 DB에 기록하고 대시보드를 자동으로 만들어 주는 안드로이드 앱입니다.

앱 이름: **Caldron AI**

---

## 설치

| 플랫폼 | 방법 | 상태 |
|---|---|---|
| Windows | [Microsoft Store](https://apps.microsoft.com/detail/9P68C75Z2QTP) | 출시 |
| 안드로이드 | 홈페이지에서 APK 다운로드 | 베타 · Google Play 출시 예정 |
| 아이폰 | 홈페이지 → Safari에서 **홈 화면에 추가** (웹앱) | 베타 |

---

## 주요 기능

- **말로 기록**: "오늘 야외에서 5km 34분 뛰었어"처럼 편하게 말하면 AI가 날짜·종목·시간·결과로 정리합니다.
- **사진으로 기록**: 러닝·클라이밍·헬스 앱의 기록 화면을 올리면 거리, 페이스, 완등 수 등을 읽어 옵니다.
- **확인 후 저장**: 처음 보는 종목은 새로 추가할지 묻고, 저장 전에 내용을 한 번 더 보여 줍니다.
- **자동 대시보드**: 기간·종목별로 기록이 쌓이면 추세 차트가 자동으로 만들어집니다.
- **백업**: 기록을 CSV로 내보내고 불러올 수 있습니다 (엑셀·파워BI 호환).

---

## 이용 안내

- 기본 AI 기능은 무료이며, 하루 이용 횟수에 제한이 있습니다.
- 무료 AI 기능은 Google Gemini 무료 등급으로 제공됩니다. 입력한 내용은 AI 학습 및 서비스 개선에 활용될 수 있으니, 얼굴·실명·연락처 등 개인을 식별할 수 있는 정보는 입력하지 마세요.
- 기록은 기본적으로 사용 중인 기기에만 저장됩니다. 앱을 삭제하거나 기기를 바꾸기 전에 CSV로 백업해 주세요.
- 자세한 내용은 앱 안의 개인정보 처리방침을 참고해 주세요.
